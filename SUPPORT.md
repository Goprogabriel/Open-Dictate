# Support

Open Dictate is an early open-source project maintained on a best-effort basis.

- Use a GitHub bug report for reproducible product problems.
- Use a feature request for product ideas.
- Use GitHub's private vulnerability reporting for security issues.
- Use [SETUP.md](./SETUP.md) for development, Firebase, Stripe, and release configuration.

Before opening an issue, search existing reports and try the latest release or current `main`.
Include the Open Dictate version, operating system version, mode (Local AI, BYOK, or managed), and
minimal reproduction steps. Remove API keys, account information, raw dictation text, file paths
containing personal names, and other private data from screenshots and logs.

Community support does not include access to contributors' OpenAI, Firebase, Stripe, or Apple
accounts. A self-hosted managed deployment is operated and billed by the person who deploys it.
